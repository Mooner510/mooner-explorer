# Mooner Explorer

Mooner Explorer는 PC와 Android를 USB/무선 ADB로 연결해 관리하는 **개인용 로컬 데스크톱 도구**입니다.

- Electron + React + TypeScript + Vite. 파일·전송·기기 관리는 Electron 메인 프로세스에서 수행합니다.
- 별도 Android 앱, 사용자 계정, 외부 서버, 자동 업데이트, 원격 분석 기능은 없습니다.
- **gharp/공용 파이프라인/CI/CD/배포 설정을 사용하지 않습니다.**
- Windows/macOS/Linux를 대상으로 소스가 구성돼 있습니다. 각 OS의 실제 호환성은 아직 검증하지 않았습니다.
- Android SDK Platform-Tools의 `adb`가 PC PATH에 필요합니다. 화면 미러링은 선택적으로 `scrcpy`가 필요합니다.
- `MOONER_ADB_PATH` 환경 변수로 adb 실행 경로를 지정할 수 있습니다.

## 구현 범위

- 연결 기기 자동 감지, USB 인증 상태 확인, 무선 ADB pair/connect/disconnect.
- 공유 저장소 `/sdcard`의 한글 포함 파일 목록, 경로 이동, 검색, 정렬, 다중 선택, 이름 변경, 복사/이동, 폴더 생성, 삭제.
- PC 로컬 폴더 패널 및 탐색, 드래그 앤 드롭 업로드, 양방향 폴더/파일 전송.
- 작업 대기열·진행률·추정 속도·ETA·취소·일시정지·재시작·디스크 영속화.
- 목적지 파일 충돌 정책(건너뛰기/고유 이름/덮어쓰기), 임시 경로를 이용한 전송 완료 후 교체·실패 청소.
- 파일 미리보기(작은 파일), 외부 열기, APK 설치·목록·실행·제거, PNG 스크린샷, 선택적 scrcpy 화면 미러링.
- 선택한 공유 저장소 파일·폴더를 로컬 폴더로 백업하거나 로컬 폴더에서 복원.

## 설계·안전 제약

- 대상 Android 경로는 `/sdcard`로 제한합니다. 루팅/보호된 앱 데이터·시스템 영역은 취급하지 않습니다.
- `adb push/pull`은 **부분 파일 바이트 오프셋 이어받기 기능이 없습니다.** 중단 작업 재시작은 임시 파일을 정리하고 **처음부터 다시 전송**합니다.
- 전송 후 임시 항목을 최종 목적지로 옮기며, 동일 이름은 기본적으로 건너뜁니다. 폴더 덮어쓰기는 별도의 백업 경로로 기존 폴더를 이동한 후 교체합니다.
- USB 연결이 끊기면 실행 중 작업을 실패로 기록합니다. 앱 재시작 시 진행 중 작업을 중단 상태로 기록하고 사용자가 다시 시도할 수 있습니다.
- 미러링은 로컬 `scrcpy` 실행파일을 사용하며 외부 기기 제어 서버를 만들지 않습니다.
- PC 로컬 선택 경로와 드래그된 파일의 접근 권한은 해당 OS 계정을 따릅니다.

## 실행 관련 안내

개발 코드만 반영했습니다. 이번 변경에서는 **의존성 설치·테스트 실행·빌드·Electron 실행·실기기 검증을 수행하지 않았습니다**. 락파일도 실제 설치로 생성·검증하지 않았습니다.

개발자가 추후 로컬에서 종속성을 설치하고 `npm run build` 후 `npm run desktop`으로 실행할 수 있도록 스크립트를 정의했습니다. 브라우저 단독 `vite`는 네이티브 API를 제공하지 않으므로 Electron 컨텍스트에서 동작합니다.

## 수동 확인 항목

USB 인증/미인증, Android 2대 연결, 무선 페어링, 한글·공백·괄호 파일명, 큰 파일/폴더 및 0바이트 파일, 연결 분리 중 전송, 중복 이름 건너뛰기/덮어쓰기/새 이름, 전송 취소·일시정지·재시도·재시작 후 상태, APK 설치/삭제, 외부 열기, macOS·Windows·Linux 권한과 경로 처리.
